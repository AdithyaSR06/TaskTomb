# TaskTomb

A C++ command-line goal management application built as a personal learning project.

## About

TaskTomb is a command-line application that allows users to create and manage personal goals. The project is being developed to strengthen my understanding of C++ programming, with a focus on object-oriented programming, problem-solving and writing structured, maintainable code.

## Current Features

- Enter and store a username
- Create and store multiple goals
- Display saved goals
- Track whether goals have been completed
- Update a goal's completion status
- Display the total number of saved goals
- Basic input validation
- Dynamic goal creation during program execution

## Concepts Practised

- Variables and data types
- Conditional statements and switch statements
- Loops, including while and do-while
- Functions, parameters and return values
- Pass by value and pass by reference
- Vectors and custom data types
- Classes and objects
- Encapsulation using private and public access modifiers
- Constructors and member initialiser lists
- Getters and setters
- Input validation using `cin.fail()`, `cin.clear()` and `cin.ignore()`

## Technologies

- C++
- Visual Studio

## Future Development

TaskTomb is an ongoing learning project. Planned improvements include:
